# Известные проблемы AQUAMER

## 1. Некоторые Android-телефоны не отправляют GPS-координаты
- Симптом: при тесте скорости координаты не записываются (NULL в БД)
- Условие: не все устройства, только часть Android
- Вероятные причины:
  - политики приватности браузера / отключённая геолокация
  - отсутствие secure context (нужен валидный сертификат)
  - пользователь не дал разрешение на доступ к геолокации
  - точность GPS низкая или долгий захват (timeout)

## 2. Измеренная скорость ниже, чем у приложения Speedtest (Ookla)
- Симптом: наш сервис показывает ниже, чем официальное приложение Speedtest
- Вероятные причины:
  - менее «агрессивный» алгоритм загрузки (размеры блоков, число параллельных потоков, тайминги)
  - порядок измерений: download → upload (состояние очередей TCP)
  - другой пиринг/сервер (у Ookla иной выбор ближайшего сервера)
  - накладные расходы HTTPS/приложение
  - состояние канала во время теста
