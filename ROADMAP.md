# Планы развития AQUAMER (ROADMAP)

## 1. Включить сервис измерения скорости в приложение
- Встроить измерение скорости (текущий web-сервис) в мобильное приложение:
  - нативное приложение (Android / iOS)
  - или встроенный WebView поверх текущего web-сервиса
- Упростить запуск для абонента (без браузера, без ввода URL)
- Возможная синхронизация результатов, авторизация абонента в приложении

## 2. Автоматически считывать номер телефона абонента и данные о сети
- В приложении автоматически получать номер абонента и все доступные данные о сети:
  - номер телефона (MSISDN)
  - данные о сети:
    - MCC/MNC (страна + оператор)
    - тип сети: 2G/3G/4G/5G
    - уровень сигнала (RSRP/RSSI)
    - оператор (PLMN), регион, соты (Cell ID)
- Важно: браузер не даёт номер телефона и данные сигнала — нужен нативный код
  - номер телефона автоматически в Android НЕ читается (нет публичного API)
  - варианты: вход через SIM-WebView + обращение к оператору, USSD/портальная
    авторизация, ручной ввод
  - данные сети: Network Information API в браузере даёт только тип связи;
    уровень сигнала/MCC/MNC — только через нативные API (TelephonyManager)
